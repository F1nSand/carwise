# 车系价格分析

传统指定车系查询可调用 price_compare、price_decay 或 region_gap；总体价格分布、多车系对比和价格关系优先使用共享分析工具。共享筛选中的车系需同时提供 brand_name 与 series。以工具实际接受并返回的筛选条件为准，检查指标有效样本、覆盖范围和 limitations；不要把代表性车源当总体统计。

价格均为平台挂牌价，不是成交价。price_decay 比较不同生产年份的挂牌车源，不表示相对新车指导价的折旧。城市或年份条件只对明确返回该条件的结果有效。

适用：用户询问车系挂牌价区间、不同年款挂牌价差异、城市挂牌价差异、总体价格分布或车龄/里程关系。
不适用：推断成交价、车况、未来价格，或缺少统计工具支持的任意条件。
