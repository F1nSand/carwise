# 共享多维分析

调用与用户问题匹配的共享分析工具。多个条件放在 `filters` 中；金额单位为元，里程为公里，车龄为年。车系使用 `{brand_name, series}`，不能只用车系文本识别。每个分析的 `params` 只包含工具 schema 声明的参数。

先检查 `status`、`reason_code`、`dataset_version`、`counts`、`limitations` 和 `methodology`。空结果、字段不支持或无效参数不能包装成成功结论。每项分析使用自己的有效样本数；不要用总体行数替代。

相关系数基于完整有效配对计算，展示散点可能经过抽样；相关不代表因果。品牌占比以当前筛选后的样本为分母，不代表全国市场份额。地区价差反映挂牌样本差异，不能证明城市导致价格不同。车龄使用快照记录值，不按当前年份重新推算。

统计事实只能引用对应工具的 evidence。不要从散点展示样本推断完整数据集，也不要把挂牌价称为成交价。不要推断车辆配置、车况、预测未来价格或未返回的筛选条件。
