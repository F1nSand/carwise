# 预算推荐

先把预算、城市、品牌、车系、能源和车龄条件交给 recommend。执行结果和 data_capabilities 决定条件是否受支持；body_type、drive_type 不可由其他字段推断。能源缺失不能视为燃油。

说明推荐是按工具既有样本门槛和解释性权重排序，不代表车况或质量保证。报告中每个车系的中位挂牌价和样本数须绑定该车系聚合证据；预算命中数不能冒充推荐车系样本数。

适用：有预算边界的车系初筛。
不适用：将推荐排序解释成个体车辆质量评价，或声称数据未支持的车型类别已筛选。
